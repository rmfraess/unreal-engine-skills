# MetaHuman

MetaHuman digital humans in Unreal Engine 5.8: authoring them with MetaHuman Creator (the in-editor Character asset, Mesh to MetaHuman, cloud auto-rigging), producing facial animation offline with MetaHuman Animator (capture data ingest, Identity, Performance, audio-driven animation), streaming facial animation live through Live Link and Live Link Hub, and the runtime side (assembled MetaHuman actors, RigLogic and the Face Control Board rig, LODs and grooms).

Skills here cover the pipeline from footage or audio to an AnimSequence playing on an assembled MetaHuman.
